## 1.2.1 Know the definition and understand the characteristics and purpose of algorithms

An **algorithm** is a set of ordered steps used to solve a problem or perform a task.

Algorithms have the following characteristics:

- they consist of clear, logical steps
- they follow a defined sequence
- they produce an output from given inputs
- they are unambiguous, so each step is clearly defined
- they can be repeated to achieve consistent results.

The purpose of algorithms is to provide a structured method for solving problems in digital software development. Algorithms enable problems to be broken down into step-by-step processes that can be represented and implemented using systems, processes, relationships, organisations of data or code.

Algorithms are used to define how a solution operates, ensuring tasks are carried out in a logical order and that outcomes are predictable and repeatable.

**Benefits**  

- support structured problem solving  
- enable repeatable and consistent results  
- provide a clear framework for implementing solutions.

**Drawbacks**  

- poorly designed algorithms may be inefficient  
- overly complex algorithms can reduce readability and maintainability.

## Exam Focus  

You should be able to:

- Define an algorithm
- Identify key characteristics of algorithms
- Explain the purpose of algorithms
- Recognise algorithm structure in representations
- Justify the use of algorithms in problem solving

!!! tip "Exam tip"
    Questions may require explanation of algorithm characteristics or purpose. Responses should link ordered steps, inputs and outputs to predictable problem-solving outcomes, and justify why algorithms are essential for creating structured digital solutions.
