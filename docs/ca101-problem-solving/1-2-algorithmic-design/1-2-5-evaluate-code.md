## 1.2.5 Benefits and drawbacks of expressing algorithms in code

Expressing algorithms in code represents logic directly using programming commands, allowing algorithms to be executed by a computer. This provides an exact and operational form of algorithm representation. :contentReference[oaicite:0]{index=0}

### Benefits of using code

- precise and unambiguous representation of logic  
- directly executable without further translation  
- supports detailed implementation of conditions, iteration and processing  
- enables immediate testing and debugging  
- ensures consistency between design and final solution.

### Drawbacks of using code

- requires programming knowledge to interpret  
- less accessible to non-technical stakeholders  
- may obscure high-level logic due to implementation detail  
- less suitable for early conceptual design.

## Exam Focus
You should be able to:
- Explain how code represents algorithms
- Identify benefits of expressing algorithms in code
- Identify drawbacks of expressing algorithms in code
- Compare code with flowcharts and written descriptions
- Justify when code is the most suitable representation method

!!! tip "Exam tip"
    Questions may require judgement of code as an algorithm representation. Responses should weigh precision and executability against accessibility and suitability for early design stages.
