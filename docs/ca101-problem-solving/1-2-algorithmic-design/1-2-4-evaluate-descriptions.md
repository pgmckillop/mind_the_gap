## 1.2.4 Benefits and drawbacks of expressing algorithms in written descriptions

Written descriptions express algorithms using structured text and hierarchical markers to indicate sequence and logical grouping. They provide a narrative representation of algorithm steps without requiring visual symbols or executable code. :contentReference[oaicite:0]{index=0}

### Benefits of using written descriptions

- accessible to both technical and non-technical audiences  
- quick to produce during early design stages  
- flexible format for outlining logic and sequence  
- useful for documenting algorithm intent and structure.

### Drawbacks of using written descriptions

- less precise than code representations  
- harder to visualise complex logic or branching  
- ambiguity may arise if wording is unclear  
- difficult to trace execution paths compared to flowcharts.

## Exam Focus
You should be able to:
- Explain how written descriptions represent algorithms
- Identify benefits of using written descriptions
- Identify drawbacks of using written descriptions
- Compare written descriptions with flowcharts and code
- Justify when written descriptions are suitable for expressing algorithms

!!! tip "Exam tip"
    Questions may require evaluation of written descriptions as an algorithm representation. Responses should balance accessibility and flexibility against reduced precision and clarity when compared to visual or coded forms.
