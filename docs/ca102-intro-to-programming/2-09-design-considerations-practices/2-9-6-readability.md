# 2.9.6 Understand the impact on readability of code style conventions

This section covers how code style conventions affect readability, maintainability and interpretation of digital software solutions.

## Naming conventions

### Features / Characteristics / Role

Naming conventions define consistent rules for naming variables, functions, procedures and other identifiers. They support understanding by making purpose and usage clearer within code.

### Benefits

- improves clarity of program intent  
- supports easier interpretation of logic  
- reduces ambiguity between identifiers  
- assists collaboration across development teams  
- simplifies debugging and maintenance  

### Drawbacks

- inconsistent naming reduces readability  
- poorly chosen names obscure purpose  
- requires discipline to apply consistently  

---

## Use of white space

### Features / Characteristics / Role

White space includes blank lines and spacing around operators and blocks of code. It is used to visually separate logical sections and improve structure.

### Benefits

- improves visual organisation of code  
- makes control structures easier to follow  
- reduces cognitive load when reading programs  
- supports identification of logical blocks  

### Drawbacks

- excessive white space can fragment code  
- inconsistent spacing reduces clarity  
- requires agreed formatting standards  

---

## Maximum line length

### Features / Characteristics / Role

Maximum line length limits how long individual lines of code should be, preventing horizontal scrolling and supporting readability across different displays.

### Benefits

- improves visibility of complete statements  
- supports consistent formatting  
- reduces need for horizontal navigation  
- improves accessibility on smaller screens  

### Drawbacks

- long expressions may require restructuring  
- enforced limits can increase line wrapping  
- may affect layout of complex statements  

---

## Judgement

Suitability depends on:

i. size and complexity of the solution  
ii. need for collaboration  
iii. maintainability requirements  
iv. development standards in use  
v. developer experience  

Applying code style conventions is suitable for improving readability and long-term maintainability, but inconsistent or overly rigid application can reduce clarity and increase development effort.
