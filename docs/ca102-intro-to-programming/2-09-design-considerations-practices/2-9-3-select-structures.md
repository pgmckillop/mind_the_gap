# 2.9.3 Determine the selection of data structures

This section covers how data structures are selected to improve execution efficiency and memory usage in digital software development.

## Selecting data structures

### Features / Characteristics / Role

Selection of data structures involves choosing appropriate ways to store and organise data so that processing can be carried out efficiently. This determines how quickly data can be accessed and how much memory is required.

It is used to:

- support efficient retrieval and manipulation of data  
- reduce unnecessary memory consumption  
- improve overall system performance  

### Benefits

- improves execution time of operations  
- supports efficient use of memory  
- enables scalable solution design  
- reduces processing overhead  
- supports maintainable program structures  

### Drawbacks

- requires understanding of performance characteristics  
- inappropriate selection reduces efficiency  
- may increase development complexity  
- optimisation decisions may reduce code readability  

---

## Ensuring efficiency of execution time

### Features / Characteristics / Role

Choosing suitable data structures minimises processing delays by enabling faster access, insertion and removal of data.

### Benefits

- reduces response times  
- supports predictable performance  
- improves user experience  

### Drawbacks

- performance optimisation can increase design effort  

---

## Ensuring efficient use of memory

### Features / Characteristics / Role

Appropriate data structures minimise memory waste by storing only necessary information in suitable formats.

### Benefits

- reduces memory consumption  
- supports operation on limited-resource systems  
- improves scalability  

### Drawbacks

- memory optimisation may restrict flexibility  

---

## Judgement

Suitability depends on:

i. volume and type of data  
ii. performance requirements  
iii. available memory resources  
iv. complexity of operations  
v. developer experience  

Selecting data structures is suitable for improving efficiency and resource use, but poor choices can reduce performance and increase complexity.

---

!!! tip "Exam tip"
    Marks are awarded for linking data structure choice to execution time and memory use. Avoid stating that structures are “efficient” — explain how selection affects performance and suitability.
