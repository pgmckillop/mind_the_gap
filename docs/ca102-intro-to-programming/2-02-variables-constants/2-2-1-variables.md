# 2.2.1 Know the definition of variables, understand their purpose and when they are used

This section covers what variables are, their role in storing data during program execution, and when they are used in digital software development.

## Definition of variables

### Features / Characteristics / Role

A variable is a named storage location that holds a value which can change while a program is running. Variables are used to store data temporarily in memory so it can be accessed, modified and processed by a program.

### Benefits

- enables dynamic handling of data  
- supports reuse of values within a program  
- allows programs to respond to changing inputs  
- improves readability through meaningful naming  
- supports calculations and logical operations  

### Drawbacks

- incorrect naming can reduce code clarity  
- misuse can lead to unexpected results  
- excessive variables increase memory usage  
- poor management can make debugging more difficult  

---

## Purpose of variables

### Features / Characteristics / Role

Variables are used to hold input values, intermediate results and outputs. They support program flow by allowing data to be updated as conditions change during execution.

### Benefits

- enables flexible program behaviour  
- supports step-by-step processing  
- allows values to be shared between different parts of a program  
- improves efficiency by avoiding repeated input  

### Drawbacks

- incorrect updates can introduce logic errors  
- overuse can complicate program structure  
- poorly scoped variables can cause unintended interactions  

---

## When variables are used

### Features / Characteristics / Role

Variables are used whenever data needs to be stored, changed or reused during program execution, including for:

- capturing user input  
- storing calculation results  
- controlling program logic  
- tracking state within a solution  

### Benefits

- supports interactive and data-driven programs  
- enables conditional and iterative processing  
- allows programs to adapt to different inputs  

### Drawbacks

- reliance on mutable values can increase complexity  
- improper initialisation may cause runtime errors  

---

## Judgement

Suitability depends on:

i. need to store or update data during execution  
ii. complexity of the solution  
iii. clarity of variable naming and scope  
iv. memory constraints  
v. developer experience  

Variables are most suitable where values must change during program execution, but excessive or poorly managed variables can reduce readability and reliability.

---

!!! tip "Exam tip"
Marks are awarded for linking the definition of variables to their purpose and use. Avoid stating that variables “store values” without explaining how this supports program logic, flexibility and suitability.
