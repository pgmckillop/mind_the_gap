# 2.8.3 Be able to develop code using validation

This section covers the development of code that applies validation checks to control data entry and ensure only acceptable values are processed in digital software development.

## Developing code using validation

### Features / Characteristics / Role

Developing code using validation involves implementing rules that test input data before it is stored or processed. Validation logic determines whether values meet defined requirements and controls program flow based on the outcome of these checks.

### Benefits

- improves accuracy of input data  
- reduces processing errors  
- supports reliable system behaviour  
- prevents invalid values from entering a solution  
- improves overall data quality  

### Drawbacks

- increases development effort  
- requires careful design of validation rules  
- overly restrictive validation can affect usability  
- does not guarantee data is correct, only that it meets defined criteria  

---

## Managing validation outcomes

### Features / Characteristics / Role

Validation outcomes determine whether processing continues, data is rejected, or corrective action is required.

### Benefits

- supports clear control of program logic  
- enables meaningful handling of invalid input  
- assists debugging of data entry issues  

### Drawbacks

- poorly designed feedback reduces clarity  
- complex validation logic increases solution complexity  

---

## Judgement

Suitability depends on:

i. criticality of data accuracy  
ii. complexity of validation rules  
iii. volume of input data  
iv. user experience requirements  
v. system performance constraints  

Developing code using validation is suitable for improving data quality at entry points, but must be balanced against usability and performance considerations.

---

!!! tip "Exam tip"
    Marks are awarded for linking validation logic to program flow. Avoid stating that validation is “added” — explain how checks control input, affect processing and influence suitability.
