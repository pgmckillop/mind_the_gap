# 2.5.4 Be able to create code using input and output

This section covers the creation of code that accepts input and produces output to enable interaction, data processing and result presentation in digital software development.

## Creating code using input

### Features / Characteristics / Role

Input is implemented to receive data from external sources such as the keyboard or text files. Creating code using input involves defining where data enters a program, assigning values to variables and preparing data for processing.

### Benefits

- enables interactive and data-driven programs  
- supports flexible program behaviour  
- allows programs to respond to changing values  
- provides starting conditions for processing  

### Drawbacks

- invalid or unexpected input can cause errors  
- requires validation to ensure reliability  
- poor variable naming reduces clarity  
- increases program complexity  

---

## Creating code using output

### Features / Characteristics / Role

Output is implemented to present results to the screen or write data to files. Creating code using output involves formatting and displaying processed data so outcomes can be observed or stored.

### Benefits

- communicates results of processing  
- supports verification of program behaviour  
- enables storage of results for later use  
- improves usability through visible feedback  

### Drawbacks

- unclear output reduces interpretability  
- formatting errors affect readability  
- excessive output can obscure key results  

---

## Creating code using combined input and output

### Features / Characteristics / Role

Combining input and output enables complete data flow through a program, from data entry to result presentation.

### Benefits

- supports end-to-end program functionality  
- enables testing of logic and calculations  
- improves understanding of program behaviour  
- supports debugging and validation  

### Drawbacks

- increases coordination between program components  
- requires careful management of data types and formatting  

---

## Judgement

Suitability depends on:

i. clarity of input and output design  
ii. complexity of program logic  
iii. reliability of input data  
iv. formatting and presentation requirements  
v. developer experience  

Creating code using input and output is suitable where interaction or data exchange is required, but poor handling can reduce reliability and clarity.

---

!!! tip "Exam tip"
Marks are awarded for linking input and output to program behaviour. Avoid showing input or output in isolation — explain how values enter the program, are processed, and are presented.
