# 2.7.6 Be able to develop code using user-written and pre-written code

This section covers the development of software solutions using both user-written and pre-written functions and procedures in digital software development.

## Using user-written functions and procedures

### Features / Characteristics / Role

User-written functions and procedures are created by the developer to perform specific tasks within a solution. They structure code into reusable components and define how data is processed and actions are performed.

### Benefits

- supports modular program design  
- improves readability and organisation  
- enables reuse of custom logic  
- simplifies testing and debugging  
- allows solutions to be tailored to specific requirements  

### Drawbacks

- requires time to design and implement  
- quality depends on developer experience  
- poorly written code reduces maintainability  
- incorrect logic affects multiple parts of a solution  

---

## Using pre-written functions and procedures

### Features / Characteristics / Role

Pre-written functions and procedures are supplied as part of the programming language or through libraries. They provide ready-made functionality that can be incorporated into solutions.

### Benefits

- reduces development time  
- provides tested and standardised functionality  
- supports consistent implementation  
- enables access to specialised capabilities  

### Drawbacks

- limited control over internal behaviour  
- dependence on external libraries  
- requires understanding of documentation  
- version changes may affect compatibility  

---

## Judgement

Suitability depends on:

i. availability of appropriate pre-written code  
ii. need for customised functionality  
iii. complexity of the solution  
iv. maintainability requirements  
v. developer experience  

Combining user-written and pre-written functions and procedures is suitable for building structured and efficient solutions, but over-reliance on either approach can reduce flexibility or control.

---

!!! tip "Exam tip"
Marks are awarded for linking user-written and pre-written code to modularity and efficiency. Avoid listing functions and procedures — explain how combining custom and library code affects development and suitability.
