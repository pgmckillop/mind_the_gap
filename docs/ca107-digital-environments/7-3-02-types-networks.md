# 7.3.2 Features of different types of networks

This section covers the features used to distinguish network types, including number of users, connection media, coverage media, and common network categories.

---

## Number of users

### Features

- Indicates how many devices or users a network supports  

### Use

- Determines network scale and capacity requirements  

### Benefits

- Supports appropriate design for small or large user groups  

### Drawbacks

- Higher user counts increase demand on bandwidth and management  

---

## Connection media

### Features

- Defines how devices are physically or wirelessly connected  

### Use

- Transfers data between networked devices  

### Benefits

- Supports flexible or fixed connectivity depending on media used  

### Drawbacks

- Performance and reliability depend on media choice  

---

## Coverage media

### Features

- Defines the geographical area a network spans  

### Use

- Determines how widely devices can connect  

### Benefits

- Enables networks to operate across small or large areas  

### Drawbacks

- Wider coverage increases complexity and cost  

---

## Network types

### Personal Area Network (PAN)

**Features**

- Very small coverage area  
- Typically connects personal devices  

**Benefits**

- Low setup complexity  
- Suitable for short-range connections  

**Drawbacks**

- Limited range  
- Supports few users  

---

### Local Area Network (LAN)

**Features**

- Covers a small physical area such as a building  

**Benefits**

- High data transfer speeds  
- Supports shared local resources  

**Drawbacks**

- Restricted geographical coverage  
- Requires local infrastructure  

---

### Metropolitan Area Network (MAN)

**Features**

- Covers a town or city  

**Benefits**

- Connects multiple LANs across a wider area  

**Drawbacks**

- More complex to manage  
- Higher infrastructure cost  

---

### Wide Area Network (WAN)

**Features**

- Covers large geographical areas  

**Benefits**

- Enables communication between distant locations  

**Drawbacks**

- Lower speeds compared with LANs  
- Greater dependence on external infrastructure  

---

### Virtual Private Network (VPN)

**Features**

- Creates a secure virtual connection over another network  

**Benefits**

- Supports remote access  
- Improves confidentiality of transmitted data  

**Drawbacks**

- Can reduce performance  
- Requires configuration and management  

---

## Judgement

Selection of network type depends on:

i. number of users  
ii. required coverage  
iii. connection media  
iv. performance expectations  
v. management and security needs  

PANs and LANs suit small-scale environments, while MANs and WANs support wider coverage. VPNs provide secure remote connectivity but introduce performance and configuration overheads. Suitability requires balancing scale, speed, coverage, and administrative complexity.

---

!!! tip "Exam tip"
    Higher marks are gained by linking **network type** to **features such as user numbers, coverage, and connection media**, and by balancing advantages (for example wider access) against drawbacks (such as reduced performance or increased complexity).
