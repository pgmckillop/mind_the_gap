## Features and use of common utilities

This section covers the features and use of common utility software used to manage, maintain, protect, and optimise digital systems.

---

## File management

### Features

- Organises files and folders  
- Supports creating, copying, moving, renaming, and deleting files  

### Use

- Manage stored data and system structure  

### Benefits

- Improves organisation and accessibility of data  
- Supports efficient retrieval and maintenance  

### Drawbacks

- Incorrect file operations can result in data loss  
- Requires user awareness of directory structures  

---

## Defragmenters

### Features

- Reorganise fragmented data on storage media  

### Use

- Improve access efficiency on fragmented storage  

### Benefits

- Can improve performance on affected storage devices  
- Optimises placement of data  

### Drawbacks

- Time-consuming  
- Limited benefit on some storage types  

---

## File compression

### Features

- Reduces file size by encoding data more efficiently  

### Use

- Save storage space and reduce transfer times  

### Benefits

- More efficient use of storage  
- Faster data transmission  

### Drawbacks

- Requires decompression before use  
- Compression and decompression consume processing resources  

---

## Package managers

### Features

- Install, update, and remove software packages  
- Manage dependencies automatically  

### Use

- Maintain software environments  

### Benefits

- Simplifies software installation and updates  
- Reduces dependency conflicts  

### Drawbacks

- Dependent on repositories and network access  
- Incorrect configurations can affect system stability  

---

## Protection software

### Features

- Detects and prevents malicious activity  

### Use

- Protect systems from security threats  

### Benefits

- Reduces risk of compromise  
- Supports system integrity  

### Drawbacks

- Can impact system performance  
- Requires regular updates to remain effective  

---

## Backup software

### Features

- Creates copies of data for recovery purposes  

### Use

- Restore data after loss, damage, or corruption  

### Benefits

- Protects against data loss  
- Supports business continuity  

### Drawbacks

- Requires storage capacity  
- Backups may become outdated if not maintained  

---

## Judgement

Selection of utility software depends on:

i. storage and performance requirements  
ii. need for data protection and recovery  
iii. software maintenance demands  
iv. available system resources  
v. risk of data loss or security compromise  

Utilities involve trade-offs between performance, protection, storage efficiency, and administrative overhead.
