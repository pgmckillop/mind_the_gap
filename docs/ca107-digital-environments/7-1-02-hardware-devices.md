# 7.1.2 Features and use of hardware devices

This section covers the features and use of different hardware device types and their roles within a digital system.

---

## Input devices

**Features**

- Used to enter data or control signals into a system  
- Convert physical actions or signals into digital input  

**Use**

- Capture user input or environmental data for processing  

**Benefits**

- Enable interaction with digital systems  
- Support data collection from users and environments  

**Drawbacks**

- Can introduce data entry errors  
- Performance and accuracy depend on device quality and user behaviour  

---

### Output devices

**Features**

- Present processed data to users or other systems  
- Convert digital data into visual, audio, or physical output  

**Use**

- Communicate results of processing  

**Benefits**

- Provide feedback and system visibility  
- Support accessibility and usability  

**Drawbacks**

- Limited by resolution, speed, or fidelity  
- May become bottlenecks in high-volume systems  

---

## Processors

Processors execute instructions and control system operations.

#### Number of cores

- Determines how many tasks can be handled simultaneously  

**Benefits**

- Improved parallel processing  
- Better multitasking capability  

**Drawbacks**

- Increased cost and power usage  

### Clock speed

- Determines how fast instructions are executed  

**Benefits**

- Faster execution of individual tasks  

**Drawbacks**

- Higher speeds increase heat and energy consumption  

### Cache size

- Small, high-speed memory located on the processor  

**Benefits**

- Reduces access time to frequently used data  
- Improves overall performance  

**Drawbacks**

- Limited capacity  
- Adds cost  

### Mobile processors

- Designed for portable devices  

**Features**

- Optimised for power efficiency and thermal limits  

**Benefits**

- Extended battery life  
- Reduced heat generation  

**Drawbacks**

- Lower performance compared with desktop processors  

---

## Main memory

### RAM (Random Access Memory)

**Features**

- Volatile memory  
- Stores programs and data currently in use  

**Use**

- Supports active processing  

**Benefits**

- Fast access speeds  
- Improves system responsiveness  

**Drawbacks**

- Data lost when power is removed  
- Limited capacity relative to storage  

## ROM (Read-only Memory)

**Features**

- Non-volatile memory  
- Stores firmware and startup instructions  

**Use**

- Supports system boot and hardware initialisation  

**Benefits**

- Retains data without power  
- Provides stable system instructions  

**Drawbacks**

- Limited write capability  
- Fixed capacity  

---

## Secondary storage

Used for long-term data storage.

### Magnetic

**Features**

- Uses magnetic media  

**Benefits**

- Large capacity  
- Lower cost per unit of storage  

**Drawbacks**

- Slower access speeds  
- Mechanical components increase failure risk  

### Solid state

**Features**

- Uses flash memory  

**Benefits**

- Fast access speeds  
- No moving parts  

**Drawbacks**

- Higher cost per unit of storage  
- Limited write cycles  

### Optical

**Features**

- Uses laser technology  

**Benefits**

- Suitable for distribution and archiving  

**Drawbacks**

- Slower read/write speeds  
- Limited capacity  

---

## Motherboard

**Features**

- Main circuit board connecting all components  

**Use**

- Enables communication between hardware devices  

**Benefits**

- Integrates system components  
- Supports expansion  

**Drawbacks**

- Compatibility constraints  
- Failure affects the entire system  

---

## Graphics processing units (GPUs)

**Features**

- Dedicated processors for graphics and parallel computation  

**Use**

- Handle visual rendering and high-volume calculations  

**Benefits**

- Offloads processing from the main processor  
- Improves graphical and computational performance  

**Drawbacks**

- High power consumption  
- Increased system cost  

---

## Network interface devices

Enable connectivity between systems.

### PCI (Peripheral Component Interconnect)

- Internal expansion interface  

**Benefits**

- High data transfer rates  

**Drawbacks**

- Requires internal installation  

### USB (Universal Serial Bus)

- External interface standard  

**Benefits**

- Ease of use  
- Wide compatibility  

**Drawbacks**

- Lower performance compared with internal interfaces  

---

## Cooling

Used to manage heat produced by hardware.

### Air cooling

**Features**

- Uses fans and heat sinks  

**Benefits**

- Lower cost  
- Simpler installation  

**Drawbacks**

- Less efficient for high-performance systems  

### Liquid cooling

**Features**

- Uses circulating liquid  

**Benefits**

- More effective heat removal  
- Supports sustained high performance  

**Drawbacks**

- Higher cost  
- Greater installation complexity  

---

## Sensors

**Features**

- Detect physical conditions and convert them into digital signals  

**Use**

- Provide environmental or system data for processing  

**Benefits**

- Enable automation and monitoring  

**Drawbacks**

- Accuracy depends on calibration and quality  

---

### Judgement

Suitability of hardware devices depends on:

i. required performance  
ii. power and thermal constraints  
iii. storage capacity and access speed  
iv. connectivity requirements  
v. cost and maintainability  

Balanced selection requires trade-offs between performance, efficiency, reliability, and budget.
