# 7.5.2 Benefits of using cloud

This section covers the benefits gained from using cloud services.

---

## Portability

### Features

- Applications and data can be accessed from different locations and devices  

### Benefits

- Supports flexible working  
- Enables rapid deployment and migration  

### Drawbacks

- Dependent on internet connectivity  
- Potential compatibility issues across platforms  

---

## Elasticity

### Features

- Resources can be increased or reduced as needed  

### Benefits

- Matches capacity to demand  
- Avoids over-provisioning  

### Drawbacks

- Rapid scaling can increase costs if not monitored  
- Requires effective management  

---

## Fewer storage limitations

### Features

- Provides access to large-scale remote storage  

### Benefits

- Reduces reliance on local hardware  
- Supports growth of data without major infrastructure changes  

### Drawbacks

- Ongoing storage costs  
- Dependence on provider availability  

---

## Cost effectiveness

### Features

- Typically uses usage-based pricing  

### Benefits

- Lower upfront investment  
- Reduced hardware and maintenance costs  

### Drawbacks

- Long-term operational costs may exceed expectations  
- Charges increase with higher usage  

---

## Judgement

Cloud adoption offers flexibility through portability and elasticity, supports large-scale storage, and can reduce initial costs. However, benefits depend on usage patterns, connectivity, and cost management.

Suitability depends on:

i. workload variability  
ii. storage demands  
iii. budget constraints  
iv. reliance on continuous connectivity  

Effective use of cloud requires balancing scalability and convenience against ongoing operational costs and dependency on providers.
