# 7.3.6 Common network components

This section covers the role of key components used within networks.

---

## Server

### Role

- Provides shared services, data, or applications to connected devices  

### Benefits

- Centralised storage and management  
- Supports multiple clients  

### Drawbacks

- Represents a single point of failure  
- Requires dedicated hardware and administration  

---

## Client

### Role

- Requests services or resources from a server  

### Benefits

- Enables users to access shared systems  
- Supports distributed working  

### Drawbacks

- Dependent on network and server availability  

---

## Router

### Role

- Directs data between different networks  
- Determines the best path for data transmission  

### Benefits

- Enables connectivity between networks  
- Supports internet access  

### Drawbacks

- Misconfiguration can disrupt connectivity  
- Adds latency to data transmission  

---

## Network switch

### Role

- Connects devices within the same network  
- Forwards data to the correct destination device  

### Benefits

- Improves efficiency of internal network traffic  
- Reduces unnecessary data transmission  

### Drawbacks

- Failure affects connected devices  
- Requires configuration and maintenance  

---

## Internet connection / internet backbone

### Role

- Provides access to external networks and online services  
- Backbone infrastructure carries large volumes of internet traffic  

### Benefits

- Enables global communication and data access  
- Supports cloud services and remote connectivity  

### Drawbacks

- Dependence on external providers  
- Outages affect all connected services  

---

## Judgement

Network components work together to provide connectivity, communication, and resource sharing. Suitability and effectiveness depend on:

i. reliability requirements  
ii. scale of users and devices  
iii. external connectivity needs  
iv. configuration and maintenance capability  
v. tolerance to component failure  

Central components such as servers, routers, and switches improve control and performance but introduce dependency risks.

---

!!! tip "Exam tip"
    Higher marks are gained by explaining the **role** of each component and balancing **benefits and drawbacks**, for example centralised services versus single points of failure. Listing components without describing purpose limits credit.
