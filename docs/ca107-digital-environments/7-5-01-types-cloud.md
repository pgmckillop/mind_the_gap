# 7.5.1 Types of cloud

This section covers the features, benefits, and drawbacks of different types of cloud environments.

---

## Private cloud

### Features

- Cloud infrastructure dedicated to a single organisation  
- Resources are not shared with external users  
- Can be hosted on-premises or by a third party  

### Benefits

- Greater control over data and systems  
- Improved security and compliance management  
- Customisable to organisational requirements  

### Drawbacks

- Higher setup and maintenance costs  
- Requires specialist management  
- Limited scalability compared with public cloud  

---

## Public cloud

### Features

- Cloud services provided over the internet  
- Infrastructure shared between multiple organisations  
- Managed by external providers  

### Benefits

- Lower upfront cost  
- Rapid scalability  
- Reduced responsibility for infrastructure management  

### Drawbacks

- Less control over underlying hardware  
- Shared resources may affect performance  
- Dependence on external providers  

---

## Judgement

Private cloud environments prioritise control and security, while public cloud environments emphasise scalability and cost efficiency.

Suitability depends on:

i. security and compliance requirements  
ii. budget constraints  
iii. scalability needs  
iv. level of control required  
v. availability of technical expertise  

Choosing between private and public cloud involves balancing control against flexibility and cost.

---

!!! tip "Exam tip"
    Higher marks are gained by comparing **private and public cloud** using **features, benefits, and drawbacks**. Answers that only define each type without evaluating suitability limit credit.
