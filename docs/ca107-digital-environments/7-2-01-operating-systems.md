# 7.2.1 Features and use of operating systems

This section covers the features and use of different types of operating systems and how they support system operation.

---

## Batch operating systems

### Features

- Designed for **non-interactive applications**  
- Optimised for **high volume** processing  
- Use **scheduling** to manage queued jobs  

### Use

- Execute large numbers of tasks automatically without user interaction  

### Benefits

- Efficient handling of repetitive, high-volume workloads  
- Minimal user intervention once jobs are submitted  

### Drawbacks

- No real-time user interaction  
- Errors may not be identified until processing completes  

---

## Multitasking operating systems

### Features

- Support **concurrent execution of multiple tasks**  
- Use **time-slicing** to share processor time  
- Manage **interrupts** to respond to system events  

### Use

- Allow multiple applications or processes to run at the same time  

### Benefits

- Improved productivity through simultaneous task execution  
- Responsive systems due to interrupt handling  

### Drawbacks

- Performance can degrade when many tasks compete for resources  
- Requires effective scheduling to avoid delays  

---

## Real-time operating systems (RTOS)

### Features

- Designed for **monitoring and control applications**  
- Support **transaction processing** with strict timing requirements  

### Use

- Operate in environments where predictable response times are essential  

### Benefits

- Deterministic behaviour  
- Reliable handling of time-critical operations  

### Drawbacks

- Less flexible than general-purpose operating systems  
- Often specialised and more complex to configure  

---

## Network operating systems

### Features

- Enable **resource sharing**  
- Provide **user management**  
- Support **communication** between connected systems  

### Use

- Manage users and shared resources across a network  

### Benefits

- Centralised control of users and resources  
- Supports collaboration and connectivity  

### Drawbacks

- Dependent on network availability  
- Increased administrative overhead  

---

## Mobile operating systems

### Features

- Designed for **smartphones and tablets**  
- Optimised for **lower processing requirements**  
- Support **increased battery life**  

### Use

- Provide operating environments for portable devices  

### Benefits

- Energy-efficient operation  
- Optimised for touch-based interfaces and mobile hardware  

### Drawbacks

- Reduced processing capability compared with desktop systems  
- Limited support for high-performance applications  

---

## Judgement

Selection of an operating system depends on:

i. interaction requirements (interactive or non-interactive)  
ii. workload volume and scheduling needs  
iii. timing constraints for monitoring, control, or transaction processing  
iv. need for shared resources and user management  
v. processing and battery limitations of target devices  

Different operating system types involve trade-offs between performance, responsiveness, flexibility, and power efficiency.
